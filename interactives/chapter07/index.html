Chapter 07 Interactives

This standalone gallery proposes two runnable JavaScript illustrations for each topic in Chapter 07, Boundary Value Problems and Sturm-Liouville Theory. The emphasis is on boundary-condition geometry, eigenvalue selection, orthogonality, eigenfunction expansions, Green's kernels, and classical physical mode shapes.

07-01 Two-Point BVPs 07-02 Eigenvalue Problems 07-03 Sturm-Liouville 07-04 Expansions 07-05 Green's Functions 07-06 Vibrating Strings 07-07 Heat Conduction

07-01 Two-Point Boundary Value Problems

These illustrations emphasize the global nature of BVPs and the role of endpoint constraints.

Endpoint Constraints vs Initial Launch

Teaching objective. Show why a BVP cannot be treated like a simple initial launch problem.
Mathematical idea shown. Two-point conditions constrain the whole solution shape across the interval.
User interactions. Sliders for left and right boundary values.

Dirichlet, Neumann, and Robin Comparison

Teaching objective. Show that different boundary conditions impose different geometric behavior at the ends.
Mathematical idea shown. Fixing value, slope, or a linear combination changes the admissible family of solutions.
User interactions. Dropdown for boundary-condition type.

07-02 Eigenvalue Problems

These illustrations show how boundary conditions select special parameter values and corresponding mode shapes.

Allowed Frequencies for a Fixed String

Teaching objective. Show that only special frequencies satisfy the endpoint constraints.
Mathematical idea shown. Nontrivial solutions exist only for discrete eigenvalues.
User interactions. Slider for the trial frequency.

Eigenfunction Nodal Count

Teaching objective. Show how higher modes gain more nodes and oscillations.
Mathematical idea shown. The mode index orders the eigenfunctions by spatial complexity.
User interactions. Slider for eigenmode number.

07-03 Sturm-Liouville Theory

These illustrations emphasize self-adjoint structure, weight functions, and orthogonality.

Weighted Orthogonality Explorer

Teaching objective. Show that orthogonality depends on the correct weight, not just on visual shape.
Mathematical idea shown. Distinct eigenfunctions become orthogonal in the weighted inner product natural to the operator.
User interactions. Sliders for two mode numbers.

Self-Adjoint Weight Comparison

Teaching objective. Show how changing the weight changes the geometry of function space.
Mathematical idea shown. The weighted inner product is part of the problem structure, not an arbitrary convention.
User interactions. Dropdown for weight type.

07-04 Eigenfunction Expansions

These illustrations show how arbitrary shapes are projected onto mode bases.

Generalized Fourier Expansion Build-Up

Teaching objective. Show how partial mode sums reconstruct a target function.
Mathematical idea shown. Expansion coefficients measure how much of each eigenmode is present.
User interactions. Dropdown for target function and slider for number of modes.

Coefficient Magnitude Spectrum

Teaching objective. Show how smoothness of the target affects how fast modal coefficients decay.
Mathematical idea shown. More regular functions generally have faster decaying expansion coefficients.
User interactions. Reuses the target selector.

07-05 Green's Functions for Boundary Value Problems

These illustrations emphasize Green's functions as point-source responses and integral kernels.

Kernel Shape for a Point Source

Teaching objective. Show how the Green's function changes when the source point moves.
Mathematical idea shown. The kernel is piecewise-defined, continuous, and changes slope across the source point.
User interactions. Slider for source location $$\xi$$.

Solution from the Integral Formula

Teaching objective. Show how a distributed source is reconstructed by integrating point-source effects.
Mathematical idea shown. The inverse operator is represented as an integral kernel.
User interactions. Dropdown for forcing profile.

07-06 Applications: Vibrating Strings

These illustrations show standing-wave modes and superposition on a fixed string.

Standing-Wave Mode Selector

Teaching objective. Show the spatial shapes of the first few fixed-end string modes.
Mathematical idea shown. Boundary conditions quantize mode shapes and frequencies.
User interactions. Slider for the mode number.

Superposition of String Modes

Teaching objective. Show that an arbitrary string shape is usually a combination of multiple standing modes.
Mathematical idea shown. Mode amplitudes oscillate in time while spatial basis functions stay fixed.
User interactions. Slider for time and a slider for the mixing ratio.

07-07 Applications: Heat Conduction

These illustrations focus on steady temperature profiles and how boundary conditions shape them.

Steady Temperature Profile with Source

Teaching objective. Show how forcing and boundary data determine the equilibrium temperature shape.
Mathematical idea shown. A steady-state BVP describes the spatial profile after transients have vanished.
User interactions. Sliders for left and right boundary temperature and source strength.

Boundary Condition Comparison

Teaching objective. Show how fixed temperature, insulated ends, and mixed exchange alter the steady profile.
Mathematical idea shown. Boundary conditions carry the physical meaning of heat exchange with the environment.
User interactions. Dropdown for boundary type.
