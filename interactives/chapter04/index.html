Chapter 04 Interactives

This standalone gallery proposes two runnable JavaScript illustrations for each topic in Chapter 04, Systems of Ordinary Differential Equations. The emphasis is on matrix form, eigenvectors, phase portraits, matrix exponentials, forcing, and system-level applications such as coupled oscillators and compartment models.

04-01 Introduction to Systems

These opening illustrations show why systems package multiple state variables together and why a phase-plane view matters.

From Second-Order Equation to First-Order System

Teaching objective. Show how a single higher-order equation becomes a first-order vector system by introducing state variables.
Mathematical idea shown. A second-order equation such as $$y'' + y = 0$$ can be rewritten with $$x_1 = y$$ and $$x_2 = y'$$.
User interactions. Sliders for initial position and initial velocity.

Time Trace and Phase Curve Together

Teaching objective. Show that a system trajectory can be viewed either in time coordinates or in state space.
Mathematical idea shown. The same solution becomes a curve in the phase plane and two time traces for the state components.
User interactions. Reuses the initial-condition sliders.

04-02 Matrices and Linear Systems

The focus here is the compact matrix form $$\mathbf{x}' = A\mathbf{x}$$ and its geometric meaning as a vector field.

Vector Field from a Matrix

Teaching objective. Show that the matrix determines a linear vector field over the plane.
Mathematical idea shown. For $$\mathbf{x}' = A\mathbf{x}$$, the arrow at each state is simply the matrix acting on that state.
User interactions. Sliders for the four matrix entries.

Trace and Determinant Explorer

Teaching objective. Connect matrix coefficients to classification tools used later in phase portraits.
Mathematical idea shown. The trace and determinant of a 2x2 matrix constrain stability and eigenvalue type.
User interactions. Reuses the matrix-entry sliders.

04-03 Eigenvalue Method: Real Distinct

These illustrations focus on eigen-directions and the way distinct real modes combine into a trajectory.

Distinct Real Eigenmodes

Teaching objective. Show how two distinct real eigenvalues generate two independent modal directions.
Mathematical idea shown. The solution is a linear combination of eigenvectors scaled by exponentials.
User interactions. Sliders for the two eigenvalues and for the initial point.

Eigendirections as Invariant Lines

Teaching objective. Show that trajectories launched exactly on an eigenvector stay on that line.
Mathematical idea shown. Eigenvectors define invariant one-dimensional solution subspaces.
User interactions. Reuses the eigenvalue sliders.

04-04 Eigenvalue Method: Complex

These illustrations emphasize spirals, centers, and the link between real part and rotational damping.

Spiral and Center Phase Portrait

Teaching objective. Show how the real part of a complex eigenvalue controls inward or outward spiral behavior.
Mathematical idea shown. Systems with complex eigenvalues rotate, with the real part setting growth or decay.
User interactions. Sliders for real part, imaginary part, and initial point.

Rotation and Amplitude in Time

Teaching objective. Connect the spiral picture in phase space to oscillatory time traces.
Mathematical idea shown. Complex eigenvalues produce sinusoidal coordinates modulated by an exponential envelope.
User interactions. Reuses the real and imaginary part sliders.

04-05 Eigenvalue Method: Repeated

These visuals focus on defective systems and the geometric role of generalized eigenvectors.

Repeated Eigenvalue with Shear

Teaching objective. Show how a repeated eigenvalue can still create nontrivial geometry when the matrix is not diagonalizable.
Mathematical idea shown. A Jordan block produces solutions with an extra polynomial factor in time.
User interactions. Sliders for repeated eigenvalue, shear parameter, and initial point.

Generalized Eigenvector Contribution

Teaching objective. Show the extra $$t e^{\lambda t}$$-type contribution created by the generalized direction.
Mathematical idea shown. Defective systems need generalized eigenvectors to complete the solution basis.
User interactions. Reuses the repeated-eigenvalue sliders.

04-06 Matrix Exponentials

These illustrations show that $$e^{At}$$ is the propagator taking an initial state to the state at time $$t$$.

Flow Map from e^(At)

Teaching objective. Show how the matrix exponential transports an initial state through time.
Mathematical idea shown. The state at time $$t$$ is $$\mathbf{x}(t)=e^{At}\mathbf{x}(0)$$.
User interactions. Sliders for diagonal matrix entries, one off-diagonal coupling, and a time value.

Columns of the Fundamental Matrix

Teaching objective. Show that the columns of $$e^{At}$$ are the solutions started from basis vectors.
Mathematical idea shown. The fundamental matrix is built from independent solution columns.
User interactions. Reuses the matrix and time sliders.

04-07 Phase Portraits for Linear Systems

These illustrations summarize the chapter’s qualitative classification viewpoint.

Trace-Determinant Classification Map

Teaching objective. Show how trace and determinant organize planar linear systems into nodes, saddles, spirals, and centers.
Mathematical idea shown. The discriminant $$\tau^2-4\Delta$$ and the sign of $$\Delta$$ classify the equilibrium.
User interactions. Sliders for trace and determinant.

Representative Phase Portrait

Teaching objective. Show a concrete phase portrait corresponding to the chosen trace-determinant location.
Mathematical idea shown. Classification is not just algebraic; it predicts geometry of trajectories.
User interactions. Reuses the trace and determinant sliders.

04-08 Nonhomogeneous Systems

These illustrations show how forcing adds a driven response on top of homogeneous dynamics.

Forced Linear System Response

Teaching objective. Show how a constant or oscillatory input bends trajectories away from pure homogeneous motion.
Mathematical idea shown. A nonhomogeneous system has a total solution equal to homogeneous plus particular response.
User interactions. Dropdown for forcing type and slider for forcing amplitude.

Particular Equilibrium Shift

Teaching objective. Show that a constant forcing shifts the equilibrium location of a stable system.
Mathematical idea shown. The particular solution can be a constant vector when the forcing is constant.
User interactions. Reuses the forcing amplitude slider.

04-09 Applications: Coupled Oscillators

The emphasis here is on normal modes and beat phenomena.

Normal Mode Comparison

Teaching objective. Show the in-phase and out-of-phase modes of a two-mass coupled oscillator.
Mathematical idea shown. Coupled systems can be decomposed into simpler normal modes with distinct frequencies.
User interactions. Sliders for coupling strength and amplitude mixing.

Beat Phenomenon

Teaching objective. Show that nearby frequencies create slow amplitude modulation.
Mathematical idea shown. Superposing close normal frequencies produces beats in the observed coordinates.
User interactions. Reuses the coupling-strength slider.

04-10 Applications: Compartment Models

These illustrations show how system language models transport and exchange among connected compartments.

Two-Compartment Exchange

Teaching objective. Show how material flows between compartments and gradually redistributes.
Mathematical idea shown. Linear systems naturally model exchange, inflow, and decay across connected reservoirs.
User interactions. Sliders for transfer rates and initial amount in the first compartment.

Conservation and Redistribution

Teaching objective. Show that exchange redistributes total mass even when the total stays fixed.
Mathematical idea shown. The sum of compartment amounts can remain invariant under pure exchange.
User interactions. Reuses the transfer-rate sliders.
