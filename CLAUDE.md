## Architecture

This is a **Jekyll-based multilingual course site** deployed to GitHub Pages. The two key structural ideas:

### 1. Multilingual Content via Custom Plugin

Content lives in parallel trees under `contents/en/` and `contents/vi/`, each mirroring the same chapter/post structure. The `_plugins/multilang.rb` plugin handles language routing — it generates localized URLs and exposes `{% t key %}` and `{% language_switch %}` Liquid tags. Search indexes are auto-generated by `_plugins/search_generator.rb` into `search-index.json` (English) and `search-index-vi.json` (Vietnamese).

### 2. Post Naming Convention

Lecture files follow `YYYY-MM-DD-ChapterNum_LectureNum_Topic.md`. The date is used by Jekyll's post system for ordering; the `chapter:`, `order:`, `lang:`, and `categories:` front matter fields are how the multilang plugin routes and groups content.

**Required front matter for every lecture post:**
```yaml
---
layout: post
title: "Lecture Title"
chapter: '01'
order: 1
owner: "Author Name"
lang: en   # or vi
categories:
- chapter01
---
```

### Content Structure

```
contents/{en,vi}/chapterXX/_posts/   ← lecture markdown files
_includes/chapter0X/enrichment.md    ← per-chapter supplemental content
home/_posts/                         ← homepage posts (intro, contents, makers)
_plugins/                            ← multilang.rb, search_generator.rb, redirect_generator.rb
public/css/, public/js/              ← Lanyon theme CSS, multilang.js, search.js
img/chapter_img/                     ← images referenced as {{ site.imgurl }}/chapter_img/...
```

## Writing Lecture Notes

### LaTeX Convention

Always use `$$...$$` for **both** inline and display math — never single `$`:

```markdown
Inline: $$\lambda$$ represents an eigenvalue

Display:
$$
\frac{d^2 y}{dx^2} + \omega^2 y = 0
$$
```

### Lecture Structure (per `.cursor/rules/lecture-notes-rule.mdc`)

Each lecture note should cover: **Title → Objectives → Prerequisites → Introduction → Key Concepts → Methods and Solution Techniques → Examples → Applications → Challenges and Extensions → Exercises → References**

Target length: 1500–3000 words depending on mathematical density.

### Reference Stack by Chapter

- **Chapters 00–03 (Foundations/ODEs)**: Boyce & DiPrima, Zill, Ross
- **Chapters 04–05 (Systems/Dynamics)**: Strogatz, Arnold
- **Chapters 07–11 (PDEs)**: Evans, Haberman
- **Chapter 12 (Functional Analysis)**: Brezis, Adams & Fournier
- **Chapter 13 (Numerical Methods)**: Ascher & Petzold, Kloeden & Platen
- **Chapters 14–15 (Advanced Theory)**: Hörmander, Trèves, Zworski

## Adding New Content

To add a new chapter, create matching directories in **both** `contents/en/chapterXX/` and `contents/vi/chapterXX/`, each with a `_posts/` subdirectory. Add corresponding `_includes/chapterXX/enrichment.md` if supplemental content is needed.

Images go in `img/chapter_img/` and are referenced as `{{ site.imgurl }}/chapter_img/filename.png`.
